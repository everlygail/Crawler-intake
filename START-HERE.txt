1. SUPABASE
Open SQL Editor -> New Query.
Paste everything from SETUP-DATABASE.sql and press Run.
Success means the database is ready.

2. GITHUB ROOT
Upload/replace every root file from this folder:
index.html
styles.css
app.js
play.html
play.css
play.js
director-admin.html
director-admin.css
director-admin.js
admin.html

netlify.toml

3. GITHUB FUNCTIONS
Inside netlify/functions, upload/replace:
crawler-api.mjs
director-api.mjs
director-admin-api.mjs
admin-api.mjs

4. NETLIFY
Keep these existing environment variables:
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
DUNGEON_ADMIN_KEY

Commit once and wait for the deploy to say Published.
